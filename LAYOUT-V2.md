# THE HOUSE — Layout v2 (DRAFT for Adam's pin pass, 2026-11-10)

Supersedes the v1 draft layout in house.ts. Built on Adam's rulings:

- **Whole-metre grid.** Every room dimension and wall length is a whole
  number of metres. (Coordinates can land on .5 where a 9m depth is
  split 5 + 4; the *lengths* are whole.)
- **Switchback stairs.** One rectangular stair box, 2.0m wide in total:
  two 1.0m runs with the divider wall built between them inside the
  2.0m. Each run climbs half a floor (1.5m); a 1m-deep landing at the
  end joins them; the walker turns 180 degrees there.
- **One stacked shaft** (Marlowe's call under "let's see what you come
  up with" — strike it if wrong): the basement flight sits directly
  under the upstairs flight in the same box. At the main floor, both
  mouths open side by side off the same strip: west run goes UP,
  east run goes DOWN.
- **Closet / headspace rule.** On the floor above a flight, the floor
  is solid over a run's LOW half (a hallway closet lives there) and
  open over its HIGH half (the well — reserved for head space).

## Footprint and column

House 12 x 9m (x -6..6, z -4.5..4.5), garage attached east.
Vertical cuts: west rooms 5m, hall column 3m, east rooms 4m (5+3+4=12).
The column (x -1..2) holds: a 1m corridor on the west (x -1..0) and
the 2.0m stair box on the east (x 0..2).

## The stair shaft

Box: x 0..2, z 0.5..3.5 (2 wide, 3 long).
- West run x 0..1, east run x 1..2 (divider inside the 2.0 total).
- Half-landing at the FRONT end: z 2.5..3.5, full box width.
- Runs: z 0.5..2.5 (2m long, 1.5m rise each).

Going UP from the main floor: enter the west run at the back end
(z 0.5), climb toward the front, +1.5m at the landing (z 2.5..3.5),
turn 180, climb the east run back toward the back, arrive upstairs
(+3m) at the back end (z 0.5) — stepping out into the upstairs back
strip, where the bathroom and office doors cluster.

Going DOWN from the main floor: enter the east run at the back end
(z 0.5), descend toward the front to the half-landing (-1.5m), turn,
descend the west run back to the basement (-3m), out at the back end.

Wells and closets:
- Main floor: OPEN well over the whole east run + landing + the west
  run's front (high) half — that's the headspace for the basement
  flight. CLOSED over the west run's back (low) half: the HALLWAY
  CLOSET, 1 x 2m, door off the hall's middle strip.
- Upstairs floor: mirrored — open well over the west run + landing +
  the east run's front half; closed over the east run's back half:
  a small LANDING CLOSET, 1 x 1m.
